# server insights

Lessons learned in `server/`: things the code doesn't make obvious and that cost
time to find out. Append new entries at the bottom:

```markdown
## <YYYY-MM-DD> <one-line title>
What happened, why it happens, and what to do instead.
```

When an insight becomes a stable rule, move it into `CLAUDE.md` (Conventions or
Gotchas) and delete it here, so nothing is said twice.
